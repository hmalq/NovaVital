NovaVital | نبض المهمة

نموذج أولي عربي لمتابعة مؤشرات العافية اليومية ضمن تحدي ناسا لمراقبة صحة روّاد الفضاء.

ماذا يفعل؟
- يسجّل ساعات النوم ومستوى التعب والمزاج.
- يحفظ الإدخالات في المتصفح ويعرض سجلًا ورسمًا للقراءات الأخيرة.
- يوفّر بيانات خيالية تجريبية لتجربة العرض.
- يربط إلى موارد ناسا عن أخطار الرحلات الفضائية ومخاطرها.

هذا نموذج تعليمي أولي، وليس أداة تشخيص أو علاج. القراءات محفوظة في المتصفح الذي أُدخلت فيه، ولا تُرسل إلى خادم.

تشغيله
نزّلوا المستودع وافتحوا ملف index.html في متصفح حديث. لا يحتاج المشروع إلى تثبيت مكتبات أو إعداد خادم.

الملفات
- index.html: محتوى الصفحة والنموذج.
- style.css: تصميم الصفحة وتوافقها مع الشاشات الصغيرة.
- app.js: حفظ الإدخالات وعرض السجل والرسم.

بيانات ناسا
تتضمن الصفحة روابط لموارد ناسا التثقيفية. لم يُضف إلى هذه النسخة ملف بيانات ناسا مفتوح بعد. اختاروا بيانات فعلية من تبويب موارد التحدي، وأضيفوا الملف ومصدره وترخيصه قبل وصفها بأنها مستخدمة في المشروع.

بيانات العرض
زر «جرّب بيانات تجريبية» يضيف قراءات خيالية لتوضيح شكل السجل والرسم. لا تمثل هذه القراءات روّاد فضاء حقيقيين ولا ينبغي استخدامها للاستنتاجات الطبية.
